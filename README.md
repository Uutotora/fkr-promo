# ФКР Москвы · промо-ролик единой системы капремонта

Промо-ролик для прототипа единой системы ФКР Москвы. Сделан кодом на [Remotion](https://www.remotion.dev/): каждый экран интерфейса перерисован как анимированный React-компонент, без скриншотов. Звук синтезирован под монтаж на Python.

**Текущая версия:** 2:28, 1920×1080, 60 fps — композиция `Promo` (`src/v3/Film3.tsx`).

- Смотреть сразу: [`preview/fkr-promo-v5-preview.mp4`](preview/fkr-promo-v5-preview.mp4) — сжатое превью
- Полное качество всех версий и саундтрек: [Releases → v5](https://github.com/Uutotora/fkr-promo/releases/tag/v5)

## Сюжет

1. Ночная Москва: 1 800 объектов, 12 000 инженерных систем.
2. «Как это работает сейчас»: пять проблем из дорожной карты.
3. Рассвет, логотип и пролёт сквозь рамку в систему.
4. Дашборд → объекты → карточка дома и график → заявка ТМЦ с проверкой по смете → маршрут согласования.
5. ИИ-ассистент: ответ с документами, сверка УПД, сопоставление номенклатуры.
6. Маркетплейс материалов: поиск, фильтры, «В потребность».
7. Электронная подпись (КЭП, Диадок).
8. Экономический эффект ≈1,05 млрд ₽ в год, переход в логотип.

## Запуск

Нужен Node.js 22+.

```sh
npm ci
npx remotion studio          # интерактивный просмотр
npx remotion render Promo out/fkr-promo.mp4 --codec h264 --crf 16
```

## Звук

Нужен Python 3.11+.

```sh
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python audio/build_v4.py   # → public/audio/v4/soundtrack.wav
```

Синтез описан в `audio/design.py` (удары, вжухи, райзеры, UI-звуки), партитура — в `audio/build_v4.py`. Звуки интерфейса — Kenney (CC0), лежат в `sfxsrc/`. Лицензионные звуки можно положить в `sfx_user/`, список слотов — в `sfx_user/README.md`.

## Структура

| Путь | Что там |
|---|---|
| `src/v3/` | текущий фильм: город, проблемы, ИИ, маркетплейс, эффекты, переходы |
| `src/scenes/`, `src/screens/` | сцены и экраны продукта (дашборд, объекты, ТМЦ, подпись) |
| `src/components/` | окно приложения, курсор, логотип, типографика, фоны |
| `src/timeline.json` | тайминг сцен, общий для картинки и звука |
| `src/v2/`, `src/Promo.tsx` | предыдущие версии (`PromoV2`, `PromoV1`) |
| `src/repetition/` | отдельный ролик «Цена повторения» (`PriceOfRepetition`) |
| `public/` | шрифт Onest, логотип, готовые саундтреки всех версий |
| `sfxsrc/`, `sfx_user/` | исходные звуки и слоты для лицензионных звуков |
| `capture/` | референсные скриншоты прототипа |
| `stills/*.jpg` | контактные листы покадровой проверки |

Кадры для проверки: `node stills.mjs <папка> 12.5 30 …` рендерит выбранные секунды в `stills/<папка>/`.

Данные в ролике демонстрационные. Экономические эффекты взяты из дорожной карты единой системы ФКР.
