## Темп (главное)
Один источник правды — `scripts/plan12.py`:
- **inserts** — сколько сюжетного времени добавлено в каких местах (старые сцены v9 на это время замирают);
- **holds** — паузы для чтения, по объёму текста на экране (`HOLD_K` — общий множитель);
- **fly()** — отдельные замедления пролётов камеры и морфов (0,7–0,8);
- `rate` — общая скорость (0,9), начало — 1,0.

`scripts/plan12.py` → `src/v12/pace_plan.json` → `scripts/pace.py` → `src/v12/pace.json` (сюжетное время каждого кадра). Скорость сюжета интегрируется плавно: торможение к паузе и разгон — без рывков (проверка печатает «max change per frame»).

## Звук
`audio/build_v8.py` (копия v7 + новые события) → `public/audio/v8/soundtrack.wav`. Время всех событий берётся из той же карты темпа. Рояль — сэмплы Salamander Grand Piano (CC-BY 3.0, Alexander Holm), струнные — VSCO-2 CE (CC0), через `audio/sampler.py`; библиотека в `audio/samples/`.
